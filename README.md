# Data Parsing VK

Скрипт собирает открытые данные профиля ВКонтакте через официальный [VK API](https://dev.vk.com/ru/reference):

- количество друзей, а также город, вуз и место работы каждого друга;
- дата рождения и возраст;
- количество постов и фото, среднее число лайков на них;
- интересы (музыка, фильмы, книги и т.д.);
- фото со стены;
- подписки на людей и сообщества.

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

Создайте приложение на [dev.vk.com](https://dev.vk.com) и впишите ключи в начало `main.py`:

```python
SERVICE_TOKEN = 'ваш токен'  # сервисный ключ приложения
USER_TOKEN = 'ваш токен'     # пользовательский токен (для фото и подписок)
```

## Запуск

```bash
python main.py durov
```

Без аргумента скрипт спросит id или короткое имя пользователя.
